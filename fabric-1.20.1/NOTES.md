# Minecraft 1.20.1 adapter – scope

Working: menu, HUD elements, zoom, freelook, freecam, waypoints (menu, compass, markers), keybind search, chat tools
(timestamps, copy), item list (items only), mouse tweaks, tool saver, auto tool/weapon, elytra swap, toggle sprint. See the module list in the menu: modules whose hooks are not ported are shown as "not available on this
Minecraft version yet" (Chat Heads, Dynamic Lights, Fullbright, No Hurtcam, Block Outline, Light Level Overlay, Food Info,
Shield Indicator, No Fog, Small Items, Profiler Chart, Villager Info, No Pumpkin Overlay, Dynamic FPS, XP Clumps).
Recipes and trades are not available in the item browser yet. Chat edge dragging and shift-drag item moving need a drag
event that this Fabric API version does not provide.
