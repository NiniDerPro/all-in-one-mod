# Minecraft 1.20.1 adapter

Same feature set as the 26.3 adapter. Differences that come from this Minecraft version:

- Profiler Chart: the game draws its chart itself at the bottom right; it cannot be moved in the HUD editor.
- FPS Boost only offers the video options that exist in this Minecraft version.
- The item browser uses the complete recipe list the server sends (this version always sends it).
- GUI atlas sprites do not exist yet: HUD elements that show a sprite from that atlas draw without it.
