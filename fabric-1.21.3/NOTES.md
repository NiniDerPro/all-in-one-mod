# Minecraft 1.21.3 adapter

Same feature set as the 26.3 adapter. Differences that come from this Minecraft / Fabric API version:

- The item browser shows the server's recipes in singleplayer; on servers it shows the default recipes of
  Minecraft (this Fabric API version has no recipe sync to the client).
- FPS Boost only offers the video options that exist in this Minecraft version.
